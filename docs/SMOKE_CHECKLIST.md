# UltScan Smoke Checklist

Короткий ручной прогон после изменений перед релизом/мерджем.

## Подготовка
1. Очистить предыдущий запуск UltScan (процесс не висит в фоне).
2. Запустить приложение обычным способом.
3. Убедиться, что язык интерфейса и хоткей известны заранее.

## Проверки критического пути
1. Приложение стартует без ошибок; иконка UltScan появляется в системном трее.
2. Открытие `Settings` из трея работает; окно активируется и не дублируется.
3. Нажатие глобального хоткея открывает режим захвата области.
4. Выделение области мышью закрывает захват и открывает оверлей + пин-панель.
5. В оверлее отображается распознанный текст (OCR).
6. При включенном переводе отображается переведенный текст.
7. Кнопка ручного обновления перевода на пин-панели обновляет результат.
8. Кнопка копирования на пин-панели копирует перевод в буфер обмена.
9. Перетаскивание (drag) пин-панелью сдвигает область оверлея.
10. Пункт трея `Repeat last` повторно открывает последний захват.
11. Пункт трея `Close overlay` корректно закрывает оверлей.
12. Смена локали EN/RU в настройках обновляет UI-строки.
13. Изменение прозрачности оверлея в настройках сразу применяется к открытому оверлею.
14. Перезапуск приложения сохраняет ранее измененные настройки.
15. Выход через пункт `Exit` корректно завершает приложение и убирает иконку из трея.

## Проверки провайдеров перевода
1. `Web` провайдер: перевод выполняется и не пустой.
2. `API v2` (если настроен): `Check connection` успешен.
3. `API v3 OAuth` (если настроен): `Check connection` успешен.

## Фиксация результата
1. Отметить дату/ветку/коммит, на котором прогон выполнен.
2. Для каждого шага отметить `PASS/FAIL`.
3. Для `FAIL` приложить короткий факт: шаг, наблюдение, скрин/лог при наличии.
