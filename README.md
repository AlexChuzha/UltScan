# UltScan

## English
UltScan is a Windows desktop app that translates text from any area of your screen in near real time.

How it works:
- Press a global hotkey to start capture mode.
- Drag to select a screen region.
- UltScan runs OCR on the selected area.
- The recognized text is translated (Google Translate Web or Google API v3).
- A movable overlay shows the recognized and/or translated text.

Key features:
- Global hotkey workflow and tray app behavior.
- Configurable overlay position, opacity, and interaction.
- Translation settings (source/target language, provider, font/theme options).
- RU/EN UI localization, onboarding/demo, and auto-update support.

## Русский
UltScan — это Windows-приложение, которое переводит текст с любой области экрана почти в реальном времени.

Как это работает:
- Нажмите глобальный хоткей, чтобы запустить режим захвата.
- Выделите нужную область экрана мышью.
- UltScan распознает текст в выбранной области (OCR).
- Распознанный текст переводится (Google Translate Web или Google API v3).
- Рядом появляется перемещаемый оверлей с распознанным и/или переведенным текстом.

Ключевые возможности:
- Работа через глобальный хоткей и иконку в системном трее.
- Настраиваемые положение, прозрачность и поведение оверлея.
- Гибкие параметры перевода (язык источника/перевода, провайдер, шрифт и цветовая тема).
- Локализация интерфейса (RU/EN), приветствие/демо и автообновления.
